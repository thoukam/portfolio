# Mon Portfolio

Portfolio personnel développé avec React, Vite et Tailwind CSS.

## Scripts

### `npm run dev`

Lance le serveur de développement Vite.

### `npm start`

Alias de `npm run dev`.

### `npm run build`

Génère le build de production dans `dist/`.

### `npm run preview`

Prévisualise localement le build de production.

## Installation

```bash
npm install
```

## Développement local

```bash
npm run dev
```

## Build de production

```bash
npm run build
```

## Stack

- React
- Vite
- Tailwind CSS
- React Icons

## Déploiement

Déploiement recommandé sur Vercel depuis GitHub.

Réglages Vercel :

- Build Command : `npm run build`
- Output Directory : `dist`
